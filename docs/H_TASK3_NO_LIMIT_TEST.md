# 任务3无限位方向测试版

当前硬件没有限位开关。本版本不会执行自动回零，也不会进入滚球闭环。

测试前：

1. 取下钢球。
2. 人工把摆杆调到水平位置。
3. 确保摆杆两方向均留有足够机械安全余量。
4. 手放在KEY4急停键旁。

切换到任务3并按确认后：

1. OLED显示`DIR0 TEST`，固件令DIR=0缓慢移动100脉冲，即暂按1 mm。
2. 观察这第一次运动时摆杆右端是抬高还是降低。
3. OLED显示`DIR RETURN`，固件用DIR=1发送相同脉冲数返回。
4. 最后显示`REPORT DIR`并禁止闭环启动。

请报告“DIR0上升”或“DIR0下降”。之后把结果写入
`config/beam_setup_config.h`，再生成正式的无限位手动零点任务3固件。

如果电机不锁定、不转、只响或方向测试后没有返回，不要放钢球；需要继续核对
D36A的EN有效电平、STEP/DIR接线、公共地、驱动电源和拨码细分。
