# 项目复盘

## 1. 最具挑战的问题

任务3负向运动时，速度微分项可能在小球距离目标仍较远时超过限幅后的比例项，使摆杆提前产生反向倾角。机构并非单纯回平，而是在远离目标时就开始反向加速，导致折返振幅逐次放大。

解决方式是把负向控制划分为远段与近段：远段允许微分项把摆杆卸载到水平，但禁止产生反向加速；进入目标附近后才允许真正反向制动。同时在首次进入终点窗口后收紧控制输出和静摩擦补偿上限。

## 2. 无效微动问题

当球位误差存在但摆杆小幅动作无法克服静摩擦时，普通PD会长期输出微小往复命令。系统增加了球位、速度和一段时间内位移进展的联合判断：确认“有误差但无进展”后逐步增加有方向的静摩擦补偿；恢复运动后再衰减，避免陷入无效循环。

## 3. 任务解耦

定点往返与行车居中属于不同工况。任务3需要较强的制动和折返逻辑，而任务4—6更重视低幅、连续、平滑的扰动抑制。因此最终将两套控制器的状态、参数和限幅独立，防止一类任务的优化破坏另一类任务。

## 4. 起步扰动补偿

车辆起步会通过惯性使钢球偏离中心。任务4同时采用车轮速度斜坡和短时反向摆杆前馈，并在斜坡结束后平滑衰减；运行中仍由视觉PD持续校正。JY61P姿态角只作为限幅前馈，失效时不会阻断视觉闭环。

## 5. 工程化措施

- 视觉数据具有CRC、序号、有效位、标定位、置信度和超时判定。
- 1 ms时基只执行轻量服务，复杂解析与控制放在分频主循环中。
- 无机械限位条件下采用人工零位、对称软行程和启动方向检查。
- 调试数据通过UART采集为CSV，支持多轮实验对比和参数回退。
